KM-07 • TIER 1 LEARNING

Reading the Drawing Before You Make the Job

This lesson is for drawing interpretation only. If the request changes to real fabrication or hazardous practical work, the safety context must be checked again.

1. What is a technical drawing?

A technical drawing is a controlled way of communicating information about an object, component or structure.

It can use lines, dimensions, views, symbols, abbreviations and notes.

Boilermaker term: Drawing interpretation means understanding what the technical drawing is communicating.

2. Different views describe the same object

A drawing may show the same object from different directions.

3. Dimensions communicate size

A dimension gives numerical information about the size or position of a feature.

Examples include length, width, height, diameter and radius.

Important: The picture size on your phone is not the real component size. Use the stated drawing information.

4. Lines, symbols and abbreviations carry meaning

Different drawing elements communicate different information. If you do not understand a symbol or abbreviation, do not guess. Check an approved source or ask for clarification.

5. Quick glossary

Dimension
A stated measurement shown on a drawing.
View
A representation of an object from a particular direction.
Front view
The object represented from the front.
Top view
The object represented as viewed from above.
Side view
The object represented from the side.
Template
A pattern or guide used to help transfer a required shape or form.

Know when learning becomes practical work

This pilot lesson is low-risk educational support.
