# 6. KM-07 — BOILERMAKER'S DRAWINGS

Official module title: Boilermaker's Drawings  
NQF Level: 4  
Credits: 12

The official curriculum lists one Knowledge Topic, `KM-07-KT01 — Boilermaker's drawings`, but that topic contains multiple substantial elements including:

- plate, pipe and structural-steel drawing concepts and terminology;
- basic geometry and units of measurement;
- drawing scales;
- line types;
- first- and third-angle orthographic projections;
- dimensioning;
- construction methods and development of components;
- basic plate, pipe and structural drawings;
- freehand sketches, isometric and orthographic projection, hidden detail and sectional views.

A single learner lesson would be too dense for the intended user.

Recommended learner structure:

- KM-07 Lesson 1 — Drawing Language: Terminology, Geometry, Units, Scale and Line Types
- KM-07 Lesson 2 — Views, Projections and Dimensioning
- KM-07 Lesson 3 — Construction and Development of Components
- KM-07 Lesson 4 — Plate, Pipe and Structural Drawings and Freehand Sketches

Target density: 4 lessons.

Reason:

This is a justified learner-facing subdivision of one official KT into four manageable lessons. The internal traceability map must show all four lessons mapping back to KM-07-KT01 and its topic elements.

# 16. NAVIGATION CONSEQUENCE

A 69-lesson flat home screen is prohibited by design.

Learner-facing architecture must be:

HOME
→ Continue Learning
→ My Knowledge Modules
→ 14 official KM boxes
→ tap one KM
→ see only that KM's 2–10 lessons
→ tap one lesson
→ learn offline
→ optional vetted visual resource
→ short learning check
→ local progress
→ clear Next Lesson

The home page therefore exposes approximately 14 curriculum choices, not 69 lesson cards.

---

# 17. UNDERSERVED-LEARNER / ACCESS GATE

Every navigation and lesson decision must be reviewed against the intended learner context:

- ordinary or older Android phone;
- small screen;
- limited and expensive data;
- intermittent or absent connectivity;
- low digital confidence;
- possible second- or third-language learning;
- need for plain language and low cognitive load;
- large tap targets;
- short, finite screens;
- written learning fully usable offline;
- visual learning clearly marked as Internet Required and supplementary only.

Governance complexity, source codes, build codes and audit detail should remain behind the learner interface unless deliberately opened in an information/about area.

---

# 18. VERIFIABILITY / AUTHENTICITY GATE

Every future learner lesson must be traceable through:

OFFICIAL KM
→ OFFICIAL KT
→ TOPIC ELEMENT(S)
→ RELEVANT IAC(S)
→ LEARNER LESSON
→ LEARNING CHECK
→ SOURCE / VERSION
→ GOVERNANCE / SAFETY NOTES

A trainer, employer, auditor or product reviewer should be able to ask why a lesson exists and receive a defensible answer from the controlled mapping.

The visual resource is never the authority. It is supplementary context only.
