Software, Files, Legislation, Ethics and Cybersecurity

Curriculum-aligned learning support for basic computers, communication software, digital responsibility, 4IR and design thinking.

← KM-10 lessons
Learning support only. This module develops basic digital literacy for the occupational environment. Workplace IT policies, privacy rules, cybersecurity controls and authorised software usage remain binding.

1. Main software programs

Different software programs have different purposes, such as creating documents, managing data, communicating or viewing technical information. Learners should understand the core purpose of the software they are authorised to use.

2. Files and folders

A file stores information, while a folder helps organise files. Clear file names and organised folders make workplace records easier to find and reduce duplication.

3. Moving and copying information

Files can be copied or moved between approved locations. Learners should take care not to overwrite current records or create uncontrolled duplicates of important documents.

4. Privacy and workplace responsibilities

Personal and workplace information must be handled responsibly. Applicable privacy rules, labour requirements and organisational policies affect how digital information may be stored, shared and used.

5. Cybersecurity basics

Cybersecurity is about protecting devices, accounts, systems and information from unauthorised access or harm. Basic good practice includes protecting passwords, checking unexpected messages and reporting suspicious activity through approved channels.

Key idea: If something digital looks suspicious or outside your authority, stop and report it rather than trying to investigate it yourself.
