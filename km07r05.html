Orthographic Projection — First and Third Angle Concepts

Curriculum-aligned theory support for Boilermaker’s Drawings.

← KM-07 lessons
Drawing and theory learning only. This lesson develops interpretation, geometry, measurement and drawing literacy. It does not authorise fabrication, cutting, welding, lifting, machining or any other hazardous practical work.

1. Multiple views

Orthographic projection represents an object using related views from different directions so its shape can be understood without perspective distortion.

2. First- and third-angle concepts

First-angle and third-angle projection arrange views differently. Learners should recognise that the projection method must be identified from the drawing convention and symbol.

3. Connecting views

Features seen in one view correspond with features in the other views. Learners should practise matching positions and relationships across views.

4. Do not mix systems

A learner should not silently combine first-angle and third-angle assumptions. If the projection method is unclear, clarification is required.

Key idea: The projection convention must remain consistent throughout interpretation.
